Required Columns (Case-insensitive):
  1. Roll Number (e.g. 1RV22CS142 or 25EU02094)
  2. Student Name
  3. Department (e.g. Computer Science, Electronics, etc.)
  4. Year/Section (e.g. III-A, IV-B, 5)
  5. Classes Conducted (Numeric > 0)
  6. Classes Attended (Numeric ≤ Classes Conducted)
  7. Data As Of (Date string, e.g. 2026-10-12)
  8. Attendance Percentage (Optional - validated against calculated value)
